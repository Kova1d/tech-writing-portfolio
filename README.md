## Что демонстрирует портфолио

- Работа со стандартами: ГОСТ 34, ГОСТ Р 59795, ЕСКД.
- Документация трёх видов: для пользователей, разработчиков и монтажников.
- Структурирование: пошаговые сценарии, таблицы, перекрёстные ссылки, глоссарии.
- Проверяемость: примеры API выполнены на реальном сервисе, ответы — реальные.
- Docs-as-code: Markdown, Git, GitHub.
